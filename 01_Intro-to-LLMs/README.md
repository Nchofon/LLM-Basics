# Generate prompts for LLM API / summarisation

## Purpose

Get familiar with an LLM API and basic file processing.

Use Google Gemini API if available for free through a localized Gmail account. You may also use paid OpenAI API, DeepInfra, Groq, or OpenRouter free models.

1. Find 10 English articles, approximately 300-1000 words each.
2. Save the articles as text file(s).
3. Create a new Google Colab notebook.
4. Upload the text files to Colab.
5. Write Python code that reads each file and uses an LLM API to summarize it.
6. Use a loop to process all articles.
7. Print 10 summaries on the screen.
8. Save all summaries as one JSON file.
